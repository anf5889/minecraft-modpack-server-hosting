## 模组服到底吃哪几样资源

### 内存：按版本和模组数估，不按“多少 G 够用”一句话

模组数量和内存需求不成线性关系。有个开了多年的公益模组服群组留下过一组实测口径：1.12.2、250 模组的服，服主启动时给 10G、跑一段时间降到 6G，也有玩家分 4G 就进来了，换优化参数后最低跑到 1.9G；同群组 1.12.2、139 模组的服占 4G；1.16.5 Forge、91 模组的服“3G 轻松开”。版本越新，单个模组的开销反而更大，1.21+ 的 ATM10 服务端就要 10G 往上。

两个场景的内存规则要分开看：

- **本机同时跑服务端和客户端**（房主自己开、朋友连进来）：分配量不超过物理内存的 50%，16G 机器最多给 8G，32G 可以给到 8G。给到 12G 会让系统和 Java 抢内存，表现就是玩着玩着闪退。判断够不够，进游戏按 F3 看 Allocated 和 Used，长期超 80% 是给少了，长期低于 30% 是给多了。
- **独立服务器只跑服务端**：没有客户端争抢，可以直接吃满，ATM10 的启动脚本里用的就是 `-Xms6G -XX:MaxRAMPercentage=95.0`。但客户端那边仍然要留 10–12G 空闲内存，官方口径是低于 16G 可能起不来。

### 磁盘：SSD 上留 20G 以上

中等体量整合包，游戏目录本体 5–8G，核心模组和运行时约 1G，存档跑图一大就破 5G，高清材质单包能到 10–20G。硬盘常年红条，加载速度断崖式下降，还会拖累区块加载。买面板服时如果存储可以加，别省这一步。

### 单核性能比核心数重要

Minecraft 的主线程扛了大部分逻辑，单核弱了核心再多也救不回来。ATM10 这类 500+ 模组的包，教程建议的是 14700K、14900K、7950X、9950X 这种高频型号，核心 4–6 个就够。雨云那条产品线把 Gold 6146、5900X、7950X、9950X、14900K 按主频铺了梯度，选的时候优先看单核档次，再看内存。

### 系统：别用 Windows 开

Windows 自身要吃内存和 CPU，同样的钱跑模组服，Linux 能多榨出一截性能。面板服默认就是 Linux 环境，这也是它比 Windows VPS 更适合新手的原因之一。

## 面板部署实操：从上传到进服

以下流程以雨云游戏云的 MCSM 面板跑 ATM10 为例，其他整合包同理。

**1. 装环境。** 安装时环境选「纯环境 / Java21」。Java 版本对不上，服务端连启动都启动不了，对照关系是：MC 1.18 及以上用 Java 17，1.16.5 左右用 Java 11 兼容性更好，1.12.2 及更老用 Java 8。ATM10 是 1.21+，配 Java 21。

**2. 记端口。** 面板里看端口映射，示例是 48652，内外端口保持一致。没有就自己加一个。

**3. 传包解压。** 进控制台，功能组 → 文件管理 → 上传服务端压缩包 → 选中压缩包解压到当前目录。

**4. 改 `server.properties`。** 把 `server-port=25565` 改成上一步的映射端口。同一份文件里还有几个值建议一起调：`max-players=20`、`view-distance=7`、`simulation-distance=5`、`online-mode=true`（正版验证，开离线服改成 false）、`white-list=true`、`spawn-protection=0`、`pvp=true`。

**5. 换启动脚本。** 打开「启动脚本(可修改).sh」，内容清空替换成对应版本的命令，**文件名不要改**：


V5.5：java -Xms6G -XX:MaxRAMPercentage=95.0 @libraries/net/neoforged/neoforge/21.1.219/unix_args.txt
V6.6：java -Xms6G -XX:MaxRAMPercentage=95.0 @libraries/net/neoforged/neoforge/21.1.224/unix_args.txt
V7.0：java -Xms6G -XX:MaxRAMPercentage=95.0 @libraries/net/neoforged/neoforge/21.1.228/unix_args.txt


**6. 启动并连服。** 回终端页点启动，客户端用面板给的映射地址加进去，形如 `xxx:33333`。

### 升级整合包时最容易翻车的一步

启动脚本里那串 NeoForge 版本号，是跟着整合包版本走的。21.1.219 对应 V5.5，21.1.224 对应 V6.6，21.1.228 对应 V7.0。整合包更新了，脚本里的数字不跟着改，服务端就是起不来，报错还看不出所以然。

升级的正确顺序是：先关服，然后只保留这些文件，其余全删——

- `world` 文件夹
- `banned-ips.json`、`banned-players.json`
- `ops.json`、`whitelist.json`
- `server_banlist_config.json`
- `server.properties`
- `usercache.json`、`usernamecache.json`

**面板服千万别顺手删掉启动脚本**，那是你自己改过的。删完再上传新版解压，把脚本里的版本号改成新的。

顺便说存档这件事。前面提到的那个公益模组服群组，主服页面上的离线时间已经标到 2026 年 4 月，添加时间是 2022 年 10 月。一个宣称“尽可能不换存档、开到世界末日”的服都会停，租服的时候就更要把备份当成自己的事：确认清楚是服务商自动备份、还是需要你自己定期把 `world` 拉下来。这一条比价格重要。

## 客户端模组和服务端模组不是一回事

买完服务器往里塞模组的时候，最先搞混的就是这个。

规则只有一条：**服务端模组必须两边都有，客户端模组可以只放本地**。放错了的表现是模组在服务器上不生效，或者客户端一进服就被踢。

具体到几个常见模组：

| 模组 | 客户端 | 服务端 | 说明 |
| --- | --- | --- | --- |
| fabric-api | 必选 | 必选 | 前置 API |
| sodium（钠） | 必选 | 无效 | 只优化客户端帧率 |
| VoxelMap（小地图） | 必选 | 无效 | 纯客户端 |
| AppleSkin（苹果皮） | 必选 | 可选 | 显示饱和度 |
| RoughlyEnoughItems | 必选 | 可选 | 查配方 |
| Tech Reborn | 必选 | 必选 | 加了新机器，两端都要 |
| Croptopia（作物盛景） | 必选 | 必选 | 加了新作物 |
| Patchouli（帕秋莉手册） | 必选 | 必选 | 文档模组 |

还有一个坑来自具体模组的平台限制。Yes Steve Model 这个改玩家模型的模组下载量 574 万，支持 1.16.5–1.21.1、Fabric/Forge/NeoForge，但它从 1.2.0 起把核心加密和渲染改成 C++ 实现，结果是 **macOS（Intel 和 Apple Silicon）客户端和服务端都不支持**，Android AArch64 只支持客户端。团队里有人用 Mac，这个包就装不了；服务器要开在 Mac 上，更别想。

还有一层是版本链。整合包要对齐四样东西：游戏主版本、加载器及版本、每个模组的版本、config 配置。差一个就报 Mod Rejection，后面跟一长串不匹配的模组名。所以整合包一定整包分发，用启动器导出或者打个压缩包发群里，让所有人解压即用。手动一个个装，十次有九次会漏。

## 到底该租还是不该租

按行业里常见的区间给个参照，这些是公开渠道的建模参考值，不是实测报价：

- **本机开服 + 虚拟局域网工具**：零服务器成本，免费房间一般限 5 人（含房主）。房主关机世界就停，且本机要同时跑服务端和客户端，16G 跑大型整合包会吃紧。
- **云主机自建**：服务端 4–8G 内存起步，月成本大约 100–300 元。要会命令行，第一次部署半天跑不掉，改个模组要上传加重启。
- **第三方面板租服**：约 30–150 元/月，按配置和人数浮动。省事，但存档在别人机器上，改冷门模组常要自己远程操作。
- **联机盒子类平台**：大多不支持自定义模组，版本更新慢，这条路对整合包基本走不通。

判断标准其实很简单：人少、只是周末开黑，本机先跑一周最划算；人数过了 10 个、或者有人白天也想上线，租服的钱才花得值。改模组的频率也要算进去——本地改完重启 30 秒验证，面板服每次都要上传再重启，调包阶段的体验差一个量级。这也是为什么很多人最后是“面板服跑成品包、本机调包”两条腿走路。

## 几个常被问到的问题

**面板服能装冷门整合包吗？** 取决于面板给不给文件管理和自定义启动脚本。像上面那种上传压缩包、自己改 `.sh` 的流程，本质上是给你一个能跑 Java 的 Linux 目录，什么包都能塞。如果面板只允许从列表里选版本、不给改脚本，那冷门包就没戏。下单前问清楚这两项权限。

**端口映射能不能自定义？** 能，而且要保证内外端口一致，改完记得同步 `server.properties` 里的 `server-port`。

**换整合包，存档还在吗？** 在 `world` 文件夹里，换包前先把它和 `ops.json`、`whitelist.json` 一起备份出来，再动其他文件。

**模组服能不能加插件？** 纯 Forge/NeoForge/Fabric 服不加插件系统，需要 Bukkit 系插件得用混合端（如 CatServer 这类），但混合端的模组兼容性要自己试。

## 下单前最后确认这几件事

按人数和模组数对号：50 模组以内、5 人以下，入门面板档够用，十几到三十几元一个月；100–250 模组、10 人上下，选 Gold 6146 那档，活动价 63 元左右；ATM10 这种 500+ 模组、20 人以上，直接上 9950X 的 12G 档，154 元左右，别在内存上省。

然后确认四件事：能不能上传自定义服务端包并改启动脚本、端口映射是否内外一致可自定义、备份是服务商的自动备份还是需要你自己拉、以及**续费价和首单价差多少**。前三条决定你能不能开成，最后一条决定你一年后还愿不愿意续。
